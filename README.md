# Kindness Drive

Play: https://joenasriani.github.io/kids-kindness-drive/

Kindness Drive is a three-lane browser game built around collecting constructive habit statements and avoiding harmful or unsafe ones.

## How it plays

The player moves a car between three lanes while habit statements travel down the road.

- collecting a constructive habit increases the score;
- missing too many constructive habits ends the run;
- contacting a harmful or unsafe habit ends the run and displays a short explanation;
- level progression increases the pace of incoming items.

Examples in the current build include sharing toys, saying please, helping others, telling the truth, washing hands, wasting food, being rude and talking to strangers.

**habit statement → player movement decision → immediate consequence → reinforcement/explanation**

## Implementation

The playable build is contained in `index.html` and uses React, ReactDOM, Babel and Tailwind loaded from public CDNs.

## Content note

The habit labels are game rules for this activity, not a validated behavioral or educational assessment.
