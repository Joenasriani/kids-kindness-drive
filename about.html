Kindness Drive

Play the game · View the source repository

Game rule

The player moves a car between three lanes while short habit statements approach. Constructive habits are collected. Harmful or unsafe habits are avoided.

habit statement → player decision → immediate game consequence → short reinforcement or explanation

Implemented behavior

  • single-player lane movement;
  • constructive and harmful/unsafe habit statements;
  • score increases for collected constructive habits;
  • miss tracking;
  • level progression with changing pace;
  • habit-specific explanation after contact with a harmful or unsafe habit.

Instructional boundary

The repository demonstrates the interaction rule and reinforcement structure. It does not contain a controlled study measuring learning, retention, behavior change, or educational effectiveness.

Deployment context

This build was used in a children's event setting and remains available as a standalone browser game.

Repository scope

This repository contains one playable game module. It does not contain a multi-game platform, learner accounts, curriculum tracking, teacher controls, or cross-game progression.
