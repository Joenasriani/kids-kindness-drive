Kindness Drive

Play the game · View the source repository

What it is

Kindness Drive is a browser-based lane game created for a children's event and retained as a reusable educational game module.

What the player does

The player moves a car between three lanes while short habit statements approach. Constructive habits should be collected. Harmful or unsafe habits should be avoided.

habit statement → player decision → immediate game consequence → short reinforcement or explanation

What is implemented

  • single-player lane movement;
  • constructive and harmful habit statements;
  • score increases for collected constructive habits;
  • miss tracking;
  • level progression with changing pace;
  • habit-specific explanation after contact with a harmful habit.

Evidence boundary

The repository demonstrates the game mechanic and its instructional structure. It does not contain a controlled study measuring learning, retention, behavior change, or educational effectiveness.

Product context

This repository contains one game module. It was deployed for a children's event within a broader educational-game direction for kids; it is not, by itself, the complete platform.
